# BreezTalk - Современный мессенджер с E2EE шифрованием

## 🌟 Что такое BreezTalk?

**BreezTalk** - это современный мессенджер с энд-ту-энд шифрованием (E2EE), разработанный для безопасной и приватной коммуникации. Название происходит от "Breeze" (легкий, свежий) и "Talk" (разговор), что отражает основную идею - легкое и безопасное общение.

## 🚀 Основные возможности

### 🔐 Безопасность и приватность
- **E2EE шифрование** - все сообщения шифруются от конца к концу
- **Diffie-Hellman ключи** - безопасный обмен ключами
- **Отсутствие доступа сервера** - сервер не может читать сообщения пользователей
- **Защита от MITM атак** - промежуточные атаки невозможны

### 💬 Функциональность общения
- **Личные сообщения** - приватные чаты между пользователями
- **Групповые чаты** - общение в группах до неограниченного количества участников
- **Каналы** - публичные каналы для вещания
- **Звонки** - аудио и видео звонки с E2EE шифрованием
- **Файлы** - обмен файлами любого типа

### 🎨 Интерфейс и удобство
- **Темная/светлая тема** - смена темы интерфейса
- **Адаптивный дизайн** - работает на всех устройствах
- **Пуш-уведомления** - мгновенные уведомления о новых сообщениях
- **Онлайн статус** - видимость пользователей онлайн
- **Поиск** - быстрый поиск пользователей и каналов

## 🏗️ Архитектура и технологии

### 🖥️ Технологический стек
- **Backend:** Node.js + Express + Socket.IO
- **Frontend:** Vanilla JavaScript + HTML5 + CSS3
- **База данных:** JSON файлы (простая и надежная)
- **Шифрование:** Встроенный E2EE на Diffie-Hellman
- **Real-time:** WebSocket через Socket.IO

### 🌐 Сетевая архитектура
- **WebSocket соединения** - мгновенная доставка сообщений
- **HTTP API** - RESTful эндпоинты для управления
- **Push уведомления** - WebPush для офлайн уведомлений
- **Файловый обмен** - загрузка и скачивание файлов

### 🔐 Система шифрования
```
Пользователь А -> [E2EE] -> Пользователь Б
     ↓                           ↓
  Приватный ключ              Приватный ключ
     ↓                           ↓
  Публичный ключ B          Публичный ключ A
```

## 📱 Как это работает?

### 🔄 Процесс регистрации
1. **Создание аккаунта** - имя, username, пароль
2. **Генерация ключей** - автоматическая генерация DH ключей
3. **Сохранение** - данные сохраняются в зашифрованном виде

### 💬 Процесс отправки сообщения
1. **Написание сообщения** - пользователь вводит текст
2. **Шифрование** - сообщение шифруется публичным ключом получателя
3. **Отправка** - зашифрованное сообщение отправляется на сервер
4. **Доставка** - сервер пересылает сообщение получателю
5. **Расшифровка** - получатель расшифровывает своим приватным ключом

### 📞 Процесс звонка
1. **Инициация** - пользователь инициирует звонок
2. **WebRTC** - устанавливается P2P соединение
3. **E2EE медиа** - аудио/видео шифруется в реальном времени
4. **Соединение** - прямое соединение между участниками

## 🛡️ Безопасность

### 🔒 Уровни защиты
- **Транспортный уровень** - HTTPS/TLS для всех соединений
- **Прикладной уровень** - E2EE для сообщений и медиа
- **Серверный уровень** - защита от DDoS и атак
- **Клиентский уровень** - защита от XSS и CSRF

### 🚫 Что НЕ хранится на сервере
- **Текст сообщений** - только зашифрованные данные
- **Медиа файлы** - шифруются перед отправкой
- **Ключи шифрования** - хранятся только у пользователей
- **Личная информация** - минимальные данные о пользователях

### ✅ Что хранится на сервере
- **Публичные ключи** - для шифрования сообщений
- **Метаданные** - время отправки, информация о доставке
- **Файловые хэши** - для проверки целостности файлов
- **Статистика** - общая информация об использовании
